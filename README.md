# ESP32 Bomb Countdown

A small ESP32 project made for learning and testing electronics, RFID and programming.

The project uses an RFID reader, OLED display, buzzer and LED. Scanning a card starts a 20-second countdown, and holding the card for 5 seconds will defuse it.

This is only a harmless electronics project for testing and educational purposes. It does not contain or use any real explosive materials or dangerous components. The "bomb" theme is just part of the project and is meant as a fun way to experiment with the ESP32.

## Components

* ESP32
* MFRC522 RFID reader
* SH1106 OLED display
* Buzzer
* LED
